# Portfólio de Mayara Souza — Cibersegurança

Página profissional com formação, experiência em suporte técnico, conhecimentos descritos no currículo e projetos planejados para estudos em segurança da informação.

## Publicar com GitHub Pages
1. Crie um repositório público chamado `portfolio-ciberseguranca`.
2. Envie `index.html` para a raiz do repositório.
3. Acesse **Settings → Pages**.
4. Selecione **Deploy from a branch**, branch `main` e pasta `/(root)`, depois clique em **Save**.

## Antes de publicar
- Confira os dados e descrições de experiência.
- Mantenha projetos planejados identificados como planejados até concluí-los.
- Não publique dados confidenciais, senhas, tokens ou informações de clientes/empregadores.
